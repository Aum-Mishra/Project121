3. Abnormal Condition Guidance

If Discharge Pressure is outside 18-22 bar:

  • Verify suction conditions
  • Inspect control valve
  • Check pump condition

If DE Vibration exceeds 4.5 mm/s:

  • Inspect alignment
  • Inspect coupling
  • Inspect bearings
  • Inspect foundation

If Bearing Temperature exceeds 85 degC:

  • Check lubrication
  • Check bearing condition
  • Escalate if temperature continues increasing

If Flow Rate is outside 450-500 m3/h:

  • Check process demand
  • Check suction conditions
  • Review pump performance
