# P-102 Feed Transfer Pump - Operating Procedure

**ApexPetro Refining Complex — Coastal Refinery, Unit 2**
**Document type:** Internal Operating Procedure
**Asset ID:** P-102
**Department:** Operations

## 1. Purpose

This procedure defines the normal operating envelope for asset P-102 (Feed Transfer
Pump) and the actions to take when a monitored parameter moves outside its
operating limit.

## 3. Operating Limits

### 3.1 Summary Table

| Parameter | Operating Limit | Unit |
|---|---|---|
| Discharge pressure | 18 - 22 | bar |
| DE vibration | <= 4.5 | mm/s |
| Bearing temperature | <= 85 | degC |
| Flow rate | 450 - 500 | m3/h |

### 3.2 Discharge Pressure

Normal range: **18-22 bar**.

If discharge pressure moves outside this range:

1. Verify suction conditions
2. Inspect control valve
3. Check pump condition

### 3.3 DE Vibration

Action threshold: **<= 4.5 mm/s**.

If DE vibration exceeds the threshold:

1. Inspect alignment
2. Inspect coupling
3. Inspect bearings
4. Inspect foundation

### 3.4 Bearing Temperature

Action threshold: **<= 85 degC**.

If bearing temperature exceeds the threshold:

1. Check lubrication
2. Check bearing condition
3. Escalate if temperature continues increasing

### 3.5 Flow Rate

Normal range: **450-500 m3/h**.

If flow rate moves outside this range:

1. Check process demand
2. Check suction conditions
3. Review pump performance

## 4. Abnormal Condition Response Procedure

### 4.1 General Sequence

1. Confirm the abnormal reading with a repeat measurement.
2. If the abnormal condition persists, raise a maintenance inspection request.
3. Maintenance/Inspection & Integrity perform a physical inspection.
4. Record findings and corrective action taken.
5. Re-measure the affected parameter after corrective action.
6. Confirm the parameter is within its operating limit before return to service.
7. Apply a monitoring period following any corrective maintenance.

## 5. Reference Incident (Historical Example)

On 7 March 2026, P-102 DE vibration was recorded at 5.6 mm/s, above the 4.5 mm/s
limit. A repeat measurement confirmed the high reading. A maintenance inspection
identified a coupling alignment issue, which was corrected. Post-maintenance
vibration was measured at 3.9 mm/s, within limit, and the pump was returned to
service with a monitoring period. This is a worked example of the abnormal-condition
procedure in Section 4.
